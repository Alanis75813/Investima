# Investima

 É um jogo de investigação onde temos três suspeitos que trabalham numa empresa, no entanto um objeto sumiu após uma reunião importante. 
O/a jogadora vai jogar explorar cada canto do jogo coletando pistas e pode levantar um hipótese de acordo com a dinâmica, o culpado 
é sorteado a cada rodada, no final temos um ranking com pontos.
